# lg_toolkit

`lg_toolkit` は、閉域自治体向け内部ツールで再利用するための**軽量テンプレート**と**小さな共通部品**を管理するリポジトリです。

- 個別ツール本体は管理しません
- 開発方針・プロンプト管理用の [`lg_toolkit_guide`](https://github.com/YanTKYS/lg_toolkit_guide) とは分離します
- 最初から大規模フレームワーク化せず、最小構成から開始します

## このリポジトリで管理するもの

- JavaScript 静的Webツール用テンプレート
- PowerShell スクリプト用テンプレート
- C# コンソール / WinForms 用テンプレート
- 複数ツールで再利用が明確になった小さな共通部品

## 管理しないもの

- 個別業務に強く依存する実装
- 単一ツールでしか使わない処理
- 外部CDN / 外部API / クラウドサービス前提の実装
- npm 等の追加インストールを当然の前提とする構成

## ディレクトリ構成

- `reference/` : 方針参照資料
- `web/` : 静的Webテンプレート
- `powershell/` : PowerShellテンプレート
- `csharp/` : C#テンプレート・方針
- `examples/` : 利用例（将来拡張用）

## 使い方（基本）

1. 利用したいテンプレートをコピーして新規ツールを作成
2. ツール固有ロジックはコピー先で実装
3. 複数ツールで重複した処理が出た場合のみ、本リポジトリへの共通化を検討

## 共通化判断の目安

- 少なくとも2つ以上のツールで同種の処理を確認
- 業務固有の前提を除去しても意味がある
- 導入しても依存関係が増えすぎない

## 共通部品の命名

共通部品を追加する場合は、名称を `lgtoolkit` に統一します。

- JavaScript 共通部品: `lgtoolkit.js`
- CSS 共通部品: `lgtoolkit.css`
- PowerShell 共通モジュール: `lgtoolkit.psm1`

テンプレート固有のファイル名は、各テンプレートの読みやすさを優先して `script.js` や `style.css` などを使用できます。

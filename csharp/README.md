# csharp

C#（コンソール / WinForms）向けテンプレートを管理するフォルダです。

## 目的

- プロジェクト開始時の最小ひな形を揃える
- 設計方針・配置ルールを共有する

## 現在の方針

- 初期段階では README 中心で運用
- `template-console/` と `template-winforms/` はプレースホルダから開始
- 実装は「複数案件で再利用が確認できた最小単位」のみ追加

## 使い方

1. 必要なテンプレートフォルダをコピー
2. コピー先で `Program.cs` / `Form1.cs` 等を作成
3. 業務依存実装はコピー先で閉じる

## 今後追加を検討する候補

- ログ初期化の最小パターン
- 設定ファイル読み込みの共通最小パターン
- エラーコード設計ガイド

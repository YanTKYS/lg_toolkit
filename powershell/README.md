# powershell

PowerShellスクリプト向けテンプレートを配置するフォルダです。

## 目的

- 閉域環境で実行できる最小テンプレートを提供
- dry-run・ログ・エラー処理の基本パターンを揃える

## 使い方

1. `template-script/` をコピーして新規スクリプトを作成
2. `-DryRun` を有効にして副作用なしで動作確認
3. 実運用時はログ出力先・エラー時の終了コード方針を業務要件に合わせる

## 共通部品の命名

PowerShell向けの共通モジュールを追加する場合は、名称を `lgtoolkit.psm1` に統一します。

ただし、`template-script/` のような個別テンプレート内では、実行開始点として理解しやすい `main.ps1` を使用できます。

## 注意

- モジュール追加インストール前提にしない
- 単一スクリプト内で完結する最小構成を優先する

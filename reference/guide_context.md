# guide_context

このファイルは `lg_toolkit` 開発時に参照する方針の要点を保持するためのコンテキストです。

> 正式なガイドは以下を参照:
> https://yantkys.github.io/lg_toolkit_guide/

## 要点（抜粋）

- 本リポジトリは個別ツール本体ではなく、再利用テンプレートを管理する
- 最初から大きなフレームワークにしない
- 外部依存（CDN / API / npm / クラウド）を前提にしない
- 共通部品は「複数ツールで繰り返し使う」ことが明確になってから追加する
- 個別業務に強く依存する処理は入れない
- まずはテンプレート中心に整備する

## 更新方針

- ガイド変更時はこの要点も更新する
- 具体実装よりも「判断基準」を優先して記載する
